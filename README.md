# character-pages

## API
https://rickandmortyapi.com/api/character?page=

## How paging works

 ?page= tells the website which page to receive. 
 
 When someone clicks NextButton page variable increases by 1. 
 
 Api sends the info about how many pages there is in its response and I use if statements to make buttons be disabled if its either on page 1 with prevButton or 42 with nextButton
